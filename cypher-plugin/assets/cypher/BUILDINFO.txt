Cypher node asset provenance
===========================

This directory preserves the existing CypherClaw native node runtime assets.
The three launchers, Unix relay helper, genesis, relay configuration, three
executables, and five Windows DLLs were copied without content changes from
cypher/ in CypherClaw commit bdd9f88d28f21fa74bcaee7e4cceab251cfb135f.
SHA256SUMS identifies the exact files. No node executable was run or rebuilt
while preparing this asset bundle.

Known completeness and verification limits
-----------------------------------------
This local preparation is not a complete corresponding-source or release
compliance certification. In particular, exact distribution patches/build
recipes and complete corresponding source for every native dependency have
not been assembled: GCC runtimes, OpenSSL, MinGW-w64/winpthreads, and the exact
Homebrew/Ubuntu/MSYS2 GMP builds remain outside this archive. The original
GMP 6.3.0 source does not establish those distribution-specific source bytes.
The Go toolchain source is not bundled; its version and license are recorded.
Native static link objects/relinking materials are not included. Package
metadata and source references establish provenance, not source completeness.

Whole-project go mod vendor on the original source snapshot did not complete:
optional browsernode-tag imports have no required cypher-services module,
cmd/evm references an absent tests package, and the bounded LevelDB package is
provided only by the build script's patch. No guessed dependency edits were
made. The archived module set comes from the actual successful binaries.
Offline rebuilding, cross-platform execution, and source reproducibility
were not tested as part of this package preparation. Complete the native
corresponding-source distribution and license review before publication.

Runtime compatibility observed from executable metadata
-------------------------------------------------------
Linux x86-64: dynamic system C/C++ runtime libraries; imported symbols require
at least GLIBC 2.38 and GLIBCXX 3.4.32. These are metadata requirements, not a
claim that every distribution providing them has been tested.
macOS ARM64: Mach-O minimum OS version 15.0, SDK 15.5; system libraries.
Windows x86-64: preserve all five supplied DLLs beside cypher.exe.
There are no Linux ARM64, macOS x86-64, or Windows ARM64 node binaries here.
Wallet generation has its own independent six-target asset set.

The native relay config is intentionally retained unchanged (414 bytes) for
the existing launchers' default behavior. No browser-llm-lab files, live node
data directories, user settings, private keys, or IPC sockets are packaged.
